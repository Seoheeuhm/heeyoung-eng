오링 규격 확인 방법과 규격표 보는 법

AS568 · JIS B 2401 · DIN ISO 3601 – 세 가지 표준의 차이와 치수 읽는 법

📌 이 가이드의 핵심

오링은 내경(ID) × 단면두께(CS) 두 치수로 규격이 결정됩니다. 어떤 규격 표준을 사용하느냐에 따라 품번 체계가 달라지므로, 사용 중인 규격 표준을 먼저 파악하는 것이 중요합니다.

1. 오링 치수의 기본: ID × CS

오링의 규격은 단 두 가지 치수로 정의됩니다:

  • ID (Inside Diameter, 내경) – 오링 내부 구멍의 지름
  • CS (Cross Section, 단면두께) – 오링 고무의 단면 지름 (오링의 "뚱뚱한 정도")

따라서 오링을 주문할 때는 "ID ○○mm × CS ○○mm" 또는 "내경 × 선경(단면)"으로 표기하면 됩니다.

⚠️ 자주 하는 실수

외경(OD)으로 규격을 말씀하시는 분이 많습니다. 외경 = 내경 + (단면두께 × 2) 이므로, 반드시 내경(ID)과 단면(CS)을 측정해 주세요.

2. 세 가지 국제 규격 표준

① AS568 (인치 규격)

미국 항공우주 표준(SAE Aerospace Standard)에서 출발한 규격으로, 전 세계에서 가장 널리 사용됩니다.

  • 단위: 인치(inch)
  • 파카 품번 예: 2-xxx (예: 2-012 = ID 0.364" × CS 0.070")
  • 총 약 400개 이상의 표준 사이즈
  • 주로 미국·글로벌 장비에서 사용

② JIS B 2401 (일본 공업 규격)

한국 · 일본 · 아시아에서 가장 많이 사용되는 규격입니다.

계열용도표기 예특징
P계실린더 피스톤/운동용P10, P21, P150운동 씰링에 최적화
G계배관 플랜지/고정용G25, G50, G300관이음 평면 밀봉
V계진공 플랜지용V30, V70진공 장비 밀봉
S계커버 고정용(소형)S10, S30소형 기기 고정 밀봉

③ DIN ISO 3601 (미터법 규격)

유럽을 중심으로 사용되는 국제 미터법 표준입니다.

  • 단위: mm
  • 표기: ID × CS (예: 10.00 × 2.00)
  • 유럽산 장비에 주로 적용

3. 규격표 보는 법 (실전)

규격표에서 찾아야 할 정보는 다음 순서입니다:

  1. 규격 표준을 확인합니다 (AS568? JIS? DIN?)
  2. 품번(번호)을 찾습니다 (예: 2-012, P21, 또는 10.00×2.00)
  3. 해당 품번의 ID(내경)과 CS(단면)를 확인합니다
  4. 공차(Tolerance)를 확인합니다 – 규격마다 허용 오차가 다릅니다

💡 실무 팁: 장비에서 규격 확인하기

① 장비 도면(Drawing)에 규격이 표기되어 있는지 확인합니다.
② 기존에 사용하던 오링의 포장·라벨에 품번이 있는지 확인합니다.
③ 위 정보가 없으면 오링을 빼서 직접 측정합니다 (캘리퍼스 사용).

4. 오링 측정 방법

사용 중이던 오링을 직접 측정할 때는 다음에 유의하세요:

  • 오링을 평평한 곳에 자연스럽게 놓은 상태에서 측정
  • 내경(ID): 오링 내부 구멍의 지름을 캘리퍼스로 측정
  • 단면(CS): 오링 고무 부분의 두께를 캘리퍼스로 측정
  • 사용 후 오링은 변형·팽윤될 수 있으므로 신품 기준 ±5% 오차 감안

⚠️ 측정이 어려운 경우

오링 홈(Groove) 치수를 알려주셔도 역산이 가능합니다. 또는 사진과 대략적인 크기만 보내주셔도 저희가 규격을 찾아드립니다.

5. 규격을 모르겠다면?

아래 정보를 희영이엔지로 보내주시면 무료로 규격을 확인해드립니다:

  • ✅ 오링 사진 (동전 등 비교 대상과 함께)
  • ✅ 대략적인 측정 치수 (ID × CS)
  • ✅ 장비명·도면 번호
  • ✅ 기존 품번이 있다면 품번
